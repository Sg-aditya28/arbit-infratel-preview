## Core Divisions
1. **Commercial Real Estate:** Flagship developments including *Arbit The 25* (Civil Lines, Gorakhpur) featuring double-height retail atriums, Grade-A corporate floor plates, and 100% UP-RERA escrow banking.
2. **Civil EPC & Municipal Infrastructure:** Turnkey state highways, reinforced concrete bridges, institutional campuses, and stormwater networks.
3. **Passive Telecom Infrastructure:** Over 850+ km of trenchless horizontal directional drilling (HDD) optical fiber ducting and 150+ telecom towers across Eastern Uttar Pradesh.

## Technology Stack
- **Framework:** Next.js 16 (Turbopack, App Router)
- **Styling:** Tailwind CSS (Custom ThemeForest Luxury Architectural Design System)
- **Language:** TypeScript
- **Icons:** Lucide React

## Getting Started

### Prerequisites
- Node.js 18+
- npm / yarn / pnpm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
